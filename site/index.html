What it does

Everything in one place

Simple buttons for the stuff that's normally a pain with lots of accounts.

🚀

Launch a bunch

Open many Roblox accounts at once and jump into the same game with one click.

🪟

Tidy windows

Snap all your Roblox windows into a neat grid automatically — no more dragging.

⚡

Max alts

Slows down the accounts you're not playing, so the one you are stays smooth.

📊

Live monitor

See each account's CPU and memory with a little preview and quick controls.

💾

Presets

Save your whole setup and bring it all back — accounts, games and windows — in one click.

🔒

Safe & yours

Your accounts are encrypted and stay only on your PC. Nothing is ever uploaded.

Get started

Up and running in 3 steps

1

Download

Grab the ZIP from GitHub and unzip it anywhere, like your Desktop.

2

Install

Double-click Install AltHub.bat. It makes a desktop shortcut for you.

3

Add accounts

Open the app, add your Roblox logins, pick a game and hit Launch. Done!

🛡️

Heads up: Windows may show a blue "protected your PC" box because the app is new — click More info → Run anyway. And running lots of accounts is against Roblox's rules and could get accounts banned, so only use your own accounts and play safe.

Ready to try it?

It's free, the code is open for anyone to read, and the Discord is there if you get stuck.
